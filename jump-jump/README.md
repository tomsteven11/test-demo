# 跳一跳 · Jump Jump

一个纯静态的「跳一跳」H5 小游戏：原生 HTML + CSS + JavaScript，使用 Canvas 2D 绘制等距伪 3D 画面。无构建、无依赖、无网络请求，音效由 WebAudio 实时合成。

## 如何运行

任选其一：

1. **直接打开**：双击 `jump-jump/index.html`，用任意现代浏览器（Chrome / Safari / Edge / Firefox）打开即可。
2. **本地静态服务**（方便手机访问同一局域网地址调试）：

   ```bash
   cd jump-jump
   python3 -m http.server 8080
   # 然后访问 http://localhost:8080
   ```

## 操作方式

| 设备 | 蓄力 | 起跳 |
| --- | --- | --- |
| 手机 / 平板 | 手指按住屏幕任意位置 | 松开手指 |
| 桌面鼠标 | 按住鼠标左键 | 松开鼠标 |
| 键盘 | 按住 `空格` | 松开 `空格` |

- 开始页 / 游戏结束页也可以按 `空格` 或 `Enter` 开始 / 重新开始。
- 右上角按钮可开关音效（设置会保存）。

## 玩法规则

- 按住蓄力，**起跳距离 = 按压时长 × 固定速度**（最长蓄力 1.4 秒）；蓄力时小人会逐渐压扁、聚集粒子。
- 落在下一个方块上 **+1 分**；落在方块**中心**附近视为「完美」，得分为 `2 × 连击数`（2、4、6……），并连击计数；普通落点会中断连击。
- 起跳很短、仍落回当前方块：不得分、游戏继续。
- 落在方块之外（或踩到边缘失衡）则坠落，游戏结束。
- 方块的形状（立方体 / 圆柱）、大小、间距、颜色都是随机的，分数越高间距越大、方块越小。
- 镜头会平滑跟随小人与下一个方块；背景色随分数缓慢变化。
- 历史最高分保存在浏览器 `localStorage`（键名 `jumpjump.best`）。

```
jump-jump/
```

## 自动化测试钩子

页面暴露了 `window.__jumpjump`（只用于调试 / 自动化测试）：`state`、`score`、`combo`、`best`，以及 `holdForCenter()`（返回当前位置跳到下一方块中心所需的蓄力毫秒数），可配合 Puppeteer / Playwright 做端到端验证。
